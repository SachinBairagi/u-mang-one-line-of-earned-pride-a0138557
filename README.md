Make.fun bounty entry: [One Line of Earned Pride](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557) ($5, free entry).

`main.py` is a pure-stdlib, deterministic Python program with no
network, no randomness and no wall clock. It writes one line of
text, 160 characters, to `<MAKEFUN_OUTPUT_DIR>/entry.txt`
(default `/output`):

> The stroke took his right hand, so he spent a year teaching his left to write, and tonight his granddaughter read his birthday card aloud without stopping once.

A quiet, earned moment of pride: a year of hard practice after a
stroke, landing in one scene, with the pride arriving by the last
word. The line was written fresh for this bounty.

Run it:

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` goes. Two
runs with different output directories produce byte-identical
files.
